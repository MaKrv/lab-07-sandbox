# Лабораторна робота №7 — Виклик і повернення: функції, стек і рекурсія

**Рівень виконання:** Standard  
 
## Опис лабораторної роботи

У лабораторній роботі виконано шість незалежних завдань, присвячених функціям, способам передавання аргументів, стеку викликів і рекурсії.

Для кожного завдання створено два файли: `taskN_prediction.cpp` та `taskN.cpp`.

У частині самостійних реалізацій для завдань 3–6 додано інтерактивне введення даних користувачем.

## Завдання 1. Факторіал, що не вліз

### Частина «Передбачте»

**Файл:** `sandbox-07/task1_prediction.cpp`

**Завдання:** дослідити рекурсивне обчислення факторіалів чисел від 10 до 13 та визначити, коли значення факторіала виходить за межі типу `int`.

**Компіляція та запуск:**

```bash
g++ -std=c++17 -Wall -Wextra sandbox-07/task1_prediction.cpp -o /tmp/sandbox07-task1-prediction
/tmp/sandbox07-task1-prediction
```

**Фактичний результат:**

```text
10! = 3628800
11! = 39916800
12! = 479001600
13! = 1932053504
```

| Мій прогноз | Справжній вивід | Чому так |
|---|---|---|
| `10! = 3628800` `11! = 39916800` `12! = 479001600` `13! = 1932053504` | `10! = 3628800` `11! = 39916800` `12! = 479001600` `13! = 1932053504` | Значення 13! перевищує діапазон 32-бітного `int`, тому виникає переповнення знакового типу з невизначеною поведінкою. |

### Частина «Напишіть самі»

**Файл:** `sandbox-07/task1.cpp`

**Завдання:** знайти найбільше число `n`, для якого факторіал ще вміщується в `int`. Обчислення виконуються в `long long`, а результат порівнюється з максимально допустимим значенням `2147483647`.

**Компіляція та запуск:**

```bash
g++ -std=c++17 -Wall -Wextra sandbox-07/task1.cpp -o /tmp/sandbox07-task1
/tmp/sandbox07-task1
```

**Фактичний результат:**

```text

```

**Завдання:** дослідити рекурсивну функцію з недосяжним базовим випадком та перевірити, що відбувається під час накопичення рекурсивних викликів.

**Компіляція:**

```bash
g++ -std=c++17 -Wall -Wextra sandbox-07/task4_prediction.cpp -o /tmp/sandbox07-task4-prediction
```

**Запуск з обмеженням стека та часу виконання:**

```bash

```

**Фактичний результат:**

```text

```

| Мій прогноз | Справжній вивід | Чому так |
|---|---|---|
